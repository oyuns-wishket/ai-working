# ERP rules — common code & domain

## Common code (Rule 8)
- Before adding shared logic, search for the existing **common-code management menu/table**.
- Add the code value there per its logic, then develop by **referencing the code value** — do not hardcode duplicates.

## Domain (Rule 7)
- When domain model/requirements are added or designed, update `docs/erp-domain/*.md` in the same change.
