# 도구의 무료·유료 기능을 실제 작업에 연결하기

외부 제작 서비스·프리미엄 예제·모델 공급원을 선택할 때 읽는다. 사용 가능한 기능을 먼저 활용하고, 계정 확인을 별도 장기 인터뷰로 만들지 않는다. 설치는 [tooling.md](tooling.md), 3D 제작은 [ai-assisted-3d.md](ai-assisted-3d.md)를 따른다.

## 서비스별로 필요한 작업만 확인

“유료 구독 중”은 해당 서비스에 관한 사용자 진술이다. 다른 서비스의 구독이나 모든 기능·API·무제한 사용을 뜻하지 않는다. 현재 요청에 필요한 작업을 아래처럼 나눠 확인한다.

| 기능 | 확인할 내용 |
|---|---|
| 생성·편집 | 텍스트/이미지 생성, 기존 모델 수정, 재질·부품·애니메이션 편집 가능 여부 |
| 내보내기 | 다운로드 가능 여부, 필요한 GLB/원본 형식, 재질·부품·animation 보존 범위 |
| 사용 권리 | 해당 asset의 상업 사용·수정·귀속표시·배포 조건; 상품 상표/외형 권리는 별도 확인 |
| 브랜딩 | 워터마크·서비스 로고 제거 가능 여부 |
| 호스팅 | 서비스 embed, 자체 asset 호스팅, runtime까지 독립 실행이 각각 가능한지 |
| 연결 | 현재 사용할 수 있는 앱·MCP·API·CLI; 웹 구독에 API 사용이 포함되는지 |
| 이용량 | 이번 작업에 필요한 크레딧/한도와 별도 과금·초과 사용 여부 |

모든 공급원을 조사하지 않는다. 필요한 기능을 충족할 후보부터 전체 흐름 **입력 → 제작 → 수정 → export → 사용 권리 → 웹 운영**을 확인한다. 생성 화면이 무료여도 다운로드나 상업 납품까지 무료인지는 별개다.

## 확인 근거와 실행

1. 기존 대화와 프로젝트 결정을 재사용한다. 이미 알려진 서비스·사용 가능 범위를 다시 묻지 않는다.
2. 현재 연결된 도구, 설치된 앱의 지원 기능, 프로젝트 설정과 공식 문서를 확인한다. 계정이 필요한 경우 이미 승인된 연결의 상태/기능 정보만 읽는다. 토큰·브라우저 쿠키·계정 파일을 광범위하게 검색해 구독을 추정하지 않는다.
3. 근거를 `사용자 진술`, `현재 공식 문서`, `연결 도구/실제 실행 확인`, `미확인`으로 구분한다. 일반 가격표와 사용자의 실제 접근 권한을 혼동하지 않는다.
4. 현재 작업 범위에서 사용 가능하고 추가 결제 없는 포함 기능은 바로 활용한다. 이미 허용된 생성·수정마다 재승인을 받지 않는다. 잔여 한도와 입력의 외부 전송 범위를 확인한 뒤 실행한다.
5. 미확인 기능에 의존해야 하면 필요한 정보 하나만 질문한다. 예: “Spline의 export 메뉴에서 자체 호스팅 다운로드를 사용할 수 있나요?” 기다리는 동안 자산 후보·콘셉트·무료 로컬 초안을 준비한다.

최초 생성은 작은 배치로 시작하고 실행 전 해당 배치의 포함 이용량/예상 소모와 추가 과금 없음을 확인한다. 결과가 나쁘면 관찰한 결함을 수정할 근거를 먼저 만들고, 같은 방식이 연속 두 번 실패하면 재생성을 멈추고 자산·제작 경로를 재평가한다. 사용자 피드백에 따른 후속 수정도 남은 승인 범위와 한도 안에서 수행한다.

권한 확인은 사용자가 구독명을 기억하는 시험이 아니다. 접근 가능한 도구에서 직접 확인하고, 직접 볼 수 없는 항목만 사용자에게 짧게 요청한다. 비밀번호·토큰을 대화로 보내게 하지 않는다.

## 선택 분기

| 현재 상태 | 에이전트가 이어서 할 일 |
|---|---|
| 필요한 유료 기능이 현재 포함되고 실행 가능 | 이번 요청의 허용된 비용/이용량 안에서 생성·편집·export·연동까지 수행 |
| 무료 기능만 사용 가능 | 권리·출력·품질·호스팅 요구를 충족하는 무료 경로 선택 |
| 웹 구독은 있지만 API는 별도 과금 | 사용 가능한 앱/MCP/로컬 export 경로 확인; API 결제를 포함으로 취급하지 않음 |
| 구독/한도 확인 불가 | 비용 없는 준비를 진행하며 실행에 필요한 사실 하나만 확인 |
| 한도 소진·권한 거부 | 같은 오류를 반복 호출하지 않고 원인 확인 후 동등한 무료 경로로 전환 |
| 무료 경로가 중요한 요구를 충족하지 못함 | 실제 대안의 결과·비용·일정 차이를 보여주고 달라지는 결정만 받음 |

무료 대체가 같은 모델 품질·상업 권리·호스팅·편집 가능성을 만족하면 승인된 범위에서 계속 진행한다. 고유 제품을 일반 모델로 바꾸거나 자체 호스팅을 외부 embed로 바꾸는 것은 동등한 대체가 아니다. 이용 가능한 대안을 구체화한 뒤 선택받는다.

구독 업그레이드·추가 구매·별도 API 결제·자동 초과 사용은 기존 구독 사용과 구분한다. 새로운 지출이 필요한 경우에만 대상·금액/한도·결과물을 제시하고 그 지출 승인을 받는다. 시안 제작 권한만으로 미승인 고객 자료를 외부 서비스에 업로드하지 않는다.

## 자주 혼동하는 경계

- **Motion**: 기본 라이브러리와 Motion+ 예제/프리미엄 컴포넌트는 구분한다. 접근 가능한 유료 권한이 있으면 목적에 맞는 보유 예제·기능을 활용하고, 없으면 무료 코어·예제로 완성한다. [Motion 문서](https://motion.dev/docs/react), [Motion+](https://motion.dev/plus)
- **Bklit UI**: chart 코드와 Studio 편집 도구의 라이선스가 다르다. 해당 코드·도구의 조건을 각각 확인한다. [공식 저장소와 라이선스](https://github.com/bklit/bklit-ui)
- **Spline**: 웹 embed와 GLB export, 코드 다운로드와 완전 self-host, AI 생성 크레딧은 별도 기능이다. GLB가 씬의 이벤트·조명·후처리를 그대로 보존하지 않는다. [가격/기능](https://spline.design/pricing), [GLB export](https://docs.spline.design/exporting-your-scene/files/exporting-as-gtlf-glb), [self-host](https://docs.spline.design/exporting-your-scene/web/exporting-as-self-hosted-project)
- **Meshy·Tripo**: 무료 생성 체험이 다운로드·상업 사용·API를 모두 허용한다고 가정하지 않는다. Meshy는 무료 다운로드 대상/횟수·귀속표시·API 과금을, Tripo는 다운로드 자격과 생성 모델의 상업 사용 조건을 확인한다. [Meshy 무료 범위](https://help.meshy.ai/en/articles/15696428-what-is-included-on-the-free-plan), [Meshy API](https://docs.meshy.ai/en), [Tripo 다운로드](https://www.tripo3d.ai/help/features/why-cant-i-download-my-model), [Tripo 상업 사용](https://www.tripo3d.ai/help/privacy-policy/how-to-use-tripo-models-commercially)
- **Blender·외부 자산**: Blender 사용 비용과 가져온 모델·텍스처·HDRI의 권리는 별개다. 오픈소스 생성 모델도 가중치·지역·배포 제한을 확인한다. Hunyuan 계열 자체 호스팅을 조건 확인 없이 무료 기본값으로 추천하지 않는다. [Blender 사용 권한](https://www.blender.org/about/)

가격·플랜명별 기능·크레딧 수량을 이 문서에 고정하지 않는다. 채택 시 공식 자료와 실제 이용 가능한 범위를 다시 확인하고 확인일을 남긴다.

## 기록 범위

프로젝트 `DESIGN.md` 또는 기존 결정 기록에는 **도구/작업, 채택 이유, 확인 근거·날짜, 납품 형식/호스팅, asset 라이선스·출처, 대체 경로**만 정리한다. [DESIGN template](../assets/DESIGN.template.md)을 재사용한다.

개인 구독 상세·계정 식별자·키·잔여 크레딧 화면은 공개 저장소에 기록하지 않는다. 필요한 계정 설정은 기기 로컬에 둔다. “사용 가능한 포함 기능으로 수행, 추가 비용 없음”처럼 익명화한 실행 판단과 납품에 필요한 권리 근거는 남길 수 있다.
