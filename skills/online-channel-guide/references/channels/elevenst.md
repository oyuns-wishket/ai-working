# 11번가 (11st Open API) — 온보딩 카드

| 항목 | 값 |
| --- | --- |
| 내부코드 | `11st` |
| 온보딩 등급 | `SELF` |
| 확인일 | 2026-07-31 |
| 출처 | 11번가 OPENAPI CENTER `openapi.11st.co.kr`, 셀러오피스, 연동 솔루션사 가이드 |

## 1. 선행조건

11번가 셀러오피스 판매자 가입. `3rd`

## 2. 신청 경로

셀러오피스(`soffice.11st.co.kr`) 로그인 → 하단 **OPEN API** → 서비스 등록
(사용 용도·담당업무·호스팅 여부) → 사용자 정보 → **11ST OPEN API KEY** →
**IP 정보(개발/상용 서버 IP)** 입력 → 저장. `3rd`

## 3. 심사·리드타임

심사 없음. **1시간 이내 발급**. IP를 등록해야 발급이 완료된다. `3rd`

## 4. 발급 결과물

API 키 1개. HTTP 헤더 `openapikey: <KEY>`로 전송한다. 쿼리파라미터도 경로도 아니다. `live`

## 5. 키 수명·회전

- ⚠️ OpenAPI 센터에 **180일 유효기간 정책** 공지가 노출된다. `docs`
- **발급된 키의 실제 만료일을 발급 시점에 기록해 캘린더·모니터링에 등록한다.**
  만료는 조용한 수집 0으로 나타난다. 실제로 운영 키 만료일이 미파악 상태로 남은 전례가 있다.

## 6. 네트워크 요건

- **고정 IP 필수.** 서비스 등록 시 개발/상용 서버 IP를 입력한다. `3rd`
- IP 등록 대기 때문에 구현이 offline-only로 멈춘 전례가 있다. 서버 프로비저닝을 먼저 한다. `live`

## 7. 권한·스코프

별도 scope 선택 없음. 서비스 등록 시 사용 용도를 기재한다. `3rd`

## 8. 역할 분담

| 주체 | 할 일 |
| --- | --- |
| `[USER]` | 셀러오피스 로그인, 서비스 등록, IP 입력, 키 수령 |
| `[AI]` | XML 파서·어댑터·fake 테스트, 발급 후 probe |
| `[3RD]` | 고객사 계정이면 담당자의 IP 등록 (대기 항목) |

## 9. 첫 호출 검증

`GET /rest/ordservices/complete/{start}/{end}` (start/end = `yyyyMMddHHmm`)를
당일 창으로 1회. 200과 XML 루트를 확인한다.

## 10. 함정

- **상태 필터 파라미터가 없다. 엔드포인트가 곧 상태다.** `live`

  | stage | status_norm |
  | --- | --- |
  | `complete` | `PAID` |
  | `packaging` | `PREPARING` |
  | `shipping` | `SHIPPING` (payload가 minimal) |
  | `dlvcompleted` | `DELIVERED` |

- 날짜는 쿼리가 아니라 **경로 세그먼트 `yyyyMMddHHmm`(12자리)**, 페이징 없이 창당 전량 반환. `live`
- 응답은 XML이고 **`ns2:` 네임스페이스**가 붙는다. `live`
- **변경일 조회가 없다.** 과거 주문의 상태 전이를 잡으려면 최근 기간 단계별 재스캔이 필수다. `live`
- 발주확인 write는 경로에 `dlvNo`가 필요한데 주문조회 원본에서의 조달 경로가
  확정되지 않아 실 write가 막힌 전례가 있다. **필수 키가 미확정인 채널은 라이브 표시·크론 활성 금지.** `live`
- 입금대기·취소/반품/교환 상태는 위 4단계로 표현되지 않는다. 관리자 전용 지표를
  `0`으로 표시하지 말고 미지원 `—`로 둔다. `live`
- 공식 rate limit 미확인. `unknown`

## 11. 폴백
