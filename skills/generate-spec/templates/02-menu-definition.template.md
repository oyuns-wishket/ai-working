## 필수 섹션 및 작성 가이드

### 1. 메뉴 구조 개요

프로젝트 계획서의 대상 사용자와 핵심 요구사항을 참고하여 전체 메뉴 트리를 설계한다.

사용자에게 질문:
- "시스템의 주요 메뉴 구조를 알려주세요. 대메뉴와 하위 메뉴를 포함해주세요."
- "GNB(Global Navigation Bar)와 LNB(Local Navigation Bar) 구분이 있나요?"

```markdown
## 1. 메뉴 구조 개요

### GNB (Global Navigation Bar)
```
├── 대메뉴1
│   ├── 하위메뉴1-1
│   ├── 하위메뉴1-2
│   └── 하위메뉴1-3
├── 대메뉴2
│   ├── 하위메뉴2-1
│   └── 하위메뉴2-2
└── 대메뉴3 (하위 없음)
```

### 메뉴 요약

| 대메뉴 | 하위 메뉴 수 | 주요 역할 |
|--------|-------------|----------|
| {대메뉴1} | N | ... |
```

### 2. 메뉴 상세

각 대메뉴별로 아래 형식을 반복한다.

```markdown
## 2. 메뉴 상세

### {대메뉴명}

- **설명**: (이 메뉴 그룹이 다루는 업무 범위)
- **대상 사용자/권한**: (어떤 역할이 접근 가능한지)

| 순서 | 하위 메뉴명 | 설명 | 대상 사용자 |
|------|-----------|------|-----------|
| 01 | {하위메뉴1} | ... | ... |
| 02 | {하위메뉴2} | ... | ... |
```

메뉴 순서(sortOrder)를 명시한다. 이 순서가 이후 단계에서 파일명의 번호 접두사가 된다.

대메뉴별로 최소 1개 이상의 하위 메뉴를 정의한다. 하위 메뉴가 없는 대메뉴는 "하위 메뉴 없음 — 대메뉴 자체가 단일 페이지" 로 명시한다.
