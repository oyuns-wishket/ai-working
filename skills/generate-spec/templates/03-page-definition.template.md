# 페이지 정의 템플릿

> 이 템플릿은 3단계 "페이지 정의" 작성을 안내한다.
> 목표 분량: 500~800 토큰/페이지 (1,750~2,800자)
> 최소 분량: 300 토큰 미만이면 보완 요청
> 의존: `docs/specs/02-menu-definition.md`를 반드시 Read한 후 진행
> 반복 단위: 하위 메뉴 1개 = 페이지 정의 1파일

## 산출물 경로

`docs/specs/pages/{NN}-{page-name}.md`

번호(NN)는 메뉴 정의의 sortOrder 기반. 파일명은 영문 kebab-case.

## frontmatter

```yaml
---
title: "{페이지명}"
stage: "page-definition"
depends-on:
  - "docs/specs/02-menu-definition.md"
created-at: YYYY-MM-DD
status: draft
---
```

## 필수 섹션 및 작성 가이드

메뉴 정의에서 해당 하위 메뉴의 설명과 대상 사용자를 참조하여 작성한다.

### 1. 페이지 개요

```markdown
## 1. 페이지 개요
- **목적**: (이 페이지가 해결하는 핵심 문제 — 한 줄)
- **소속 메뉴**: {대메뉴} > {하위메뉴}
- **대상 사용자**: (접근 가능한 역할 나열)
```

### 2. 핵심 기능 목록

사용자에게 질문: "이 페이지에서 사용자가 수행할 수 있는 주요 기능(액션)을 알려주세요."

```markdown
## 2. 핵심 기능 목록

| 기능명 | 설명 | 우선순위 |
|--------|------|---------|
| {기능1} | (한 줄 설명) | 높음/중간/낮음 |
| {기능2} | ... | ... |
```

최소 2개, 최대 10개 내외의 기능을 정의한다. 10개 초과 시 페이지 분할을 검토한다.

### 3. 진입/이탈 경로

```markdown
## 3. 진입/이탈 경로
- **진입**: (어디서 이 페이지로 오는지 — GNB, 알림, 다른 페이지 링크 등)
- **이탈**: (이 페이지에서 어디로 가는지 — 다음 업무 페이지, 상세 드릴다운 등)
```

### 4. 와이어프레임 힌트

```markdown
## 4. 와이어프레임 힌트
- **레이아웃**: (1컬럼 / 2컬럼 / 마스터-디테일 / 탭 / 위저드 등)
- **주요 컴포넌트**: (테이블, 폼, 카드 그리드, 차트 등)
- **특이사항**: (해당 시 — 실시간 업데이트, 드래그앤드롭 등)
```
